# Delta Smart System website

Static, dependency-light corporate website. Open `index.html` locally or deploy the contents of this folder to any static web host.

## Before launch

Replace the visibly bracketed contact details and `EMAIL-PLACEHOLDER` in the contact and footer areas with verified company information. Replace `YOUR-DOMAIN.example` in `index.html`, `robots.txt`, and `sitemap.xml` with the public domain. Add a real social profile only when its URL is confirmed. The Open Graph image URL is an editable placeholder; add a branded share image at that location before launch.

The contact form currently validates fields in the browser and confirms that the information is ready. It does not send or store submissions. Connect a chosen email provider or server endpoint before accepting enquiries.

## Files

- `index.html` — semantic page content, metadata and organization schema
- `styles.css` — responsive styles and reduced-motion support
- `script.js` — mobile navigation, scroll reveals and client-side validation
- `favicon.svg` — temporary geometric brand mark, replaceable with the official logo
- `robots.txt` and `sitemap.xml` — domain placeholders to update before launch
